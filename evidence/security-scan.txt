- bandit (Python code in backend/app): 0 issues at any severity.
- pip-audit (backend/requirements.txt, all pinned packages): no known vulnerabilities.
- npm audit --omit=dev (what ships to the browser):
  * BEFORE: 3 HIGH findings, all in react-router-dom 6.26.2 (open-redirect advisories GHSA-2w69-qvjg-hvjx, GHSA-2j2x-hqr9-3h42).
  * FIX APPLIED: react-router-dom pinned to 6.30.6 (same major version). Build, 12 vitest tests and all e2e tests pass after the change.

    Accepted for the hackathon; tracked as follow-up.

  tailwind 3's file watcher (braces/micromatch, postcss-selector-parser) and vitest (tinypool, @vitest/mocker; critical). These run only on the developer machine / CI during build
  and test; none of them is shipped in dist/. Fixing them needs major upgrades (vite 6+/tailwind 4) or vitest 2.1.9+;
  left as a follow-up rather than changing the build chain days before the demo.
- npm audit (e2e/ Playwright project): 0 vulnerabilities.
