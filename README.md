# Halcyon DeliveryLens

EvoHack 2026 · Team **InfinityStacks** (Sravan Kumar D · Sai M · Dinesh K) · Problem 2: late deliveries at Halcyon Logistics.

**In one line:** DeliveryLens finds why deliveries are late, fixes each cause with AI agents
(Claude on AWS Bedrock), and proves how much on-time delivery improves.

> Work in progress. A full guide to the folders and documents is coming in the next commits.

| Folder | What is inside |
|---|---|
| `data/halcyon-dataset/` | The dataset the stakeholder gave us (synthetic, unchanged) |
| `analysis/` | Script that finds the causes of late deliveries, and its output |
| `docs/` | Plain-English documents; `docs/reference/` has the original hackathon files |
| `backend/`, `frontend/`, `infra/` | The application (being built) |
| `ai-logs/` | Record of the AI agents used in each role |
| `.claude/`, `tools/fde-toolkit/` | Claude Code skills and agents the team uses |
